# Q-03 — the library view

Unfold the workspace (Mod+\), open the palette (Mod+Shift+P) and run **Library**. Judge by looking:

- The first screenful: the title, the path under it, the reasons in secondary text, the 3 px accent bar and wash on the active row. Is a row of two to six fixed lines too tall for a "dense" list? (The mock's one-line rows are Q-03's density control, not built.)
- A query with chips: `cache kind:report model:x`. The amber, dashed chip with its words; the completion list under the field; the status line's "of N files" and "Measuring N of M files" for `words:>500`.
- The status marks (changed, pinned) are an icon with hidden words; the row's aria-label says them.
- The toolbar, tab row and strip stay over the view. Should the strip and tabs hide while the library shows?
- Narrow window: the preview pane drops below 760 px.
