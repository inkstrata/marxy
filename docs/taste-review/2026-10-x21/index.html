Unfolded: toolbar, tabs, strip, sidebar, inspector, status bar

Mock: 01-workspace (unfolded, Read)

Largest visible gap. The bands stop at x = 1188: a 252 px dead column on the right (the grid keeps a mirror of the sidebar so the column stays centred) and an empty 26 px status bar across the window; in Paper both are white blocks on the off-white page. Toolbar is words, not icons (1 svg against the mock's 17), no segmented Read/Split/Source, no + / Export / inspector toggle, title and folder on one line. Sidebar: flush panel, no search, no section chevrons, 26 px rows (mock 28, inset card r 13). Tabs: 182 px, close always shown, active tab drawn as a button. Strip: one word, no kind label. No inspector (W-09 is PR #607).

Source, unfolded

Mock: 02-source

The mock's Source is a framed editor: path, encoding, endings, indent, bytes and lines on a 24 px top bar, a 16 px column ruler, a 24 px bottom bar (Ln, Col, byte, measures, the character under the caret), an 8 px right strip of marks. The app draws the bare text (14/21, ADR-0067) centred on the page with none of the bars and no gutter for Markdown (L-06.1 and 10-spec: off for Markdown). The frame is V-05, planned and never carded.

Mock: 01-workspace (folded, Source)

Folded, the mock keeps the frame, centred at 960 px; the app shows the bare column. The bytes facts (encoding, endings, size, caret position) are nowhere in the app's Source today, folded or not.

Palette, commands (Shift+Mod+P)

Mock: 01-workspace + palette on >

149 rows with no group header, no glyph and no secondary line; thirteen "Show this file as ..." rows sit in the first screen. The mock groups commands (Navigate, File, View, ...) with an icon, the group as a second line, a key chip, and a preview of what the command does.

Library

Mock: 05-collections

Against the mock: no table columns (measure, modified, status), no filter menus beside the query, scopes as plain text tabs, rows of 49 px two-line, a header without the collection's facts, plain buttons in the preview.
