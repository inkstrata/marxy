A pre-release for macOS on Apple silicon. It is the first release of Marxy as it is built now: a new
code base from the ground up, not an update of 0.1.0.

## Install

1. Download `Marxy_0.2.0_aarch64.dmg` below, open it and drag Marxy to Applications.
2. Open Marxy once. macOS refuses it, because this build is not notarised by Apple.
3. Open System Settings, Privacy and Security, and choose **Open Anyway** beside the line about Marxy.
   Confirm with your password. Marxy opens, and opens normally from then on.

From a terminal, the same thing in one step: `xattr -dr com.apple.quarantine /Applications/Marxy.app`.

Right-click and Open no longer gets past this on macOS 15 and later.

Needs macOS 13 or later on an Apple silicon Mac (M1 or newer). Intel Macs are not supported.

## What Marxy is

A reader for the files on your machine. It opens Markdown, plain text, source code, data (JSON, YAML,
TOML, XML, JSON Lines, CSV), logs, diffs and terminal sessions, notebooks, mail, HTML, archives, PDFs,
images, audio and video, fonts, spreadsheets, Word documents and decks, certificates, programs and
SQLite databases, and shows each the way that suits it.

## New since 0.1.0

- **Read and Source.** Read sets the file as a page; Source is an editor over the exact bytes. One key
  switches, and your place is kept.
- **Exact bytes.** Only the bytes you change are changed: line endings, byte order marks and encodings
  are kept, and a save replaces the file in one step.
- **Many kinds of file**, each with its own reading: a data tree, a table, a coloured listing, a card of
  facts, a viewer, or the bytes.
- **Work on what you read.** A cursor over a document's sections, blocks, rows and entries; single keys
  copy, collect, fold and transform them; edits are staged and saved as one patch, with earlier copies
  kept as versions.
- **Many files.** Tabs, two panes side by side, places (folders you add), search and replace across
  them, an outline, comparison of two files or versions, and export to a web page, PDF, Markdown or a
  bundle.
- **Looks.** Dark and light themes, a Studio to make your own, and a typesetter with hyphenation and
  hanging punctuation.
- **Local.** Settings are a `config.toml`. Nothing is sent anywhere; remote images load only when you
  allow them.

## Known limits

- macOS on Apple silicon only. There is no Windows download yet, and Linux has never been built.
- The build is signed ad hoc, not with an Apple Developer ID, hence the steps above.
- Closing the window quits Marxy.
- Very long Markdown files (around a megabyte) can take a long time to open.
