# Plan delta — 2026-09-28, full-codebase bugcatch pass

> Filed at the author's request after a correctness-focused review pass across
> `packages/core`, `packages/typeset`, `packages/theme`, `packages/shell-api` and
> `apps/desktop` (frontend and the Rust shell). The pass ran five parallel reviewers, one per
> area, each reading current source (not a diff) and hunting for real bugs with a concrete
> failure scenario. Landing key **MARXY-279**, with its own `no-dispatch` row. It ran in
> `../marxy-wt/MARXY-279`, cut from `origin/main`.

## What the pass found

Of the ~35 candidate findings, the highest-confidence and most severe were fixed directly in a
companion out-of-plan PR (see "Fixed directly" below). The ten filed here needed either a
dedicated design decision, a frozen-contract ADR, or more test surface than fits a same-day fix
alongside a dozen other patches.

| Key | Area | What's wrong |
| --- | --- | --- |
| MARXY-280 | typeset | Cached font metrics survive a resize even when a fluid type scale changed the real font size |
| MARXY-281 | typeset | A NaN stretch value silently poisons every line-break cost comparison instead of failing loudly |
| MARXY-282 | typeset | Baseline-grid pushes assume a margin-collapse delta that their own padding insertion can invalidate |
| MARXY-283 | typeset | The `justif` engine gives hyphens no extra demerits, unlike `ragged.ts`'s TeX-faithful model |
| MARXY-284 | theme | `variants = []` in theme.toml passes validation because `[].every(...)` is vacuously true |
| MARXY-285 | shell-api | The two stub `Shell` implementations are hand-duplicated; a new member can be added to one and forgotten in the other |
| MARXY-286 | desktop (Rust) | `unwatch_root` can miss its table entry (and leak a thread) after `canonicalize()` fails, and blocks the async executor on start/stop |
| MARXY-287 | desktop (Rust) | `image_size` reports a real I/O error identically to "not an image" |
| MARXY-288 | desktop (frontend) | A failed live-reload watch disables itself with only a console warning |
| MARXY-289 | core | `relativePath` assumes `from` is a directory; untested today |

## What this pass does

All ten rows sit in the **ops lane** (no phase), matching the reviewed area (typeset and theme
work is deep in already-shipped Phase 1/Phase 3 machinery, not new phase build-out) and the
precedent MARXY-267 set for filed-in-passing defects. **Phases 0–4 in `orchestration/deps.json`
are unchanged.** None of the ten depend on each other or on in-flight work.

`MARXY-285` is the one contract-adjacent story: `packages/shell-api/src/`
is in `scripts/registry.json`'s `frozen` list, so its card asks for an ADR-only PR that changes no
behaviour, the way MARXY-94 and MARXY-268 did.

## Fixed directly, not filed

A same-day out-of-plan PR (a sibling to this one) applies the smaller, lower-risk fixes from the
same pass directly: a CRLF-boundary off-by-one in `packages/core/src/buffer/buffer.ts`'s `lineOf`,
a missing zero-size guard in `packages/core/src/render/images.ts`'s WebP decoder, a CR-only
line-ending miss in `packages/core/src/operations/copy-code-clean.ts`, the `data:` URL bypass of
the no-network rule in `packages/theme/src/css-urls.ts`, the `ch`-unit clamp bypass in
`packages/theme/src/loader.ts`, a stale open-document dirty-flag in
`apps/desktop/src/commands/edits.ts`, an orphaned theme watcher on rapid restart in
`apps/desktop/src/theme/user-theme.ts`, a missing listener install-once guard in
`apps/desktop/src/palette/view.ts`, a containment check for `allow_asset_scope` and a
read-aborts-on-one-bad-entry bug in `apps/desktop/src-tauri/src/commands/fs.rs`'s `read_dir`, and
a silently-discarded watcher poll error in `apps/desktop/src-tauri/src/watch/spawn_notify.rs`.

## Not filed, and why

- **`packages/core/src/sanitize/sanitize-html.ts`'s non-`img` remote-subresource gap:** no
  attribute in the current allow-list can trigger it; speculative until the allow-list grows.
- **`packages/core/src/sourcemap/section.ts`'s unasserted top-level-heading invariant:** holds
  today; nothing currently violates it.
- **`packages/core/src/parse/byte-offsets.ts`'s negative-offset asymmetry:** no real caller passes
  a negative offset; the strict-path implementation already clamps.
- **`packages/core/src/operations/align-table-pipes.ts`'s undocumented width-floor invariant:** the
  `Math.max(3, ...)` floor makes it safe today; a comment would be enough, not a story.
- **`packages/theme/src/loader.ts`'s "delete the whole declaration on an unparseable value"
  behaviour:** matches the documented intent (leave the default kept); the comment's wording is
  loose, the behaviour is not a bug.
- **`apps/desktop/src/palette/search.ts`'s frecency ranking short-circuit:** no concrete inversion
  found, low confidence.
- **`apps/desktop/src-tauri/src/commands/fs.rs`'s `mtime_ms` truncating cast:** harmless at any
  realistic filesystem date.
