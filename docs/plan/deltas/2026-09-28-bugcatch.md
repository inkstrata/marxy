## What the pass found

Of the ~35 candidate findings, eight of the highest-confidence and most severe were fixed
directly in a companion out-of-plan PR, MARXY-290 (see "Fixed directly" below). The eleven filed
here needed either a dedicated design decision, a frozen-contract ADR, or more test surface than
fits a same-day fix alongside a dozen other patches. Four further candidates were re-verified
against the actual code during the fix pass and turned out not to be real, reachable bugs; those
are recorded under "Re-verified and dropped" rather than fixed or filed.

## What this pass does

All eleven rows sit in the **ops lane** (no phase), matching the reviewed area (typeset and theme
work is deep in already-shipped Phase 1/Phase 3 machinery, not new phase build-out) and the
precedent MARXY-267 set for filed-in-passing defects. **Phases 0–4 in `orchestration/deps.json`
are unchanged.** None of the eleven depend on each other or on in-flight work.

`MARXY-285` is the one contract-adjacent story: `packages/shell-api/src/`
is in `scripts/registry.json`'s `frozen` list, so its card asks for an ADR-only PR that changes no
behaviour, the way MARXY-94 and MARXY-268 did.

## Fixed directly, not filed

MARXY-290 (a sibling out-of-plan PR) applies the smaller, well-verified, low-risk fixes from the
same pass directly, each with a regression test: the `data:` URL bypass of the no-network rule in
`packages/theme/src/css-urls.ts`; the `ch`/`px` unit-family clamp bypass in
`packages/theme/src/loader.ts`; a stale open-document dirty-flag baseline in
`apps/desktop/src/commands/edits.ts` and `document.ts`; a CR-only line-ending miss in
`packages/core/src/operations/copy-code-clean.ts`; a NaN badness value in
`packages/typeset/src/ragged.ts`; a read-aborts-on-one-bad-entry bug in
`apps/desktop/src-tauri/src/commands/fs.rs`'s `read_dir`; a canonicalize-mismatch watcher-thread
leak in `apps/desktop/src-tauri/src/main.rs`'s `unwatch_root`; and a silently-discarded watcher
poll error in `apps/desktop/src-tauri/src/watch/spawn_notify.rs`.

## Re-verified and dropped

Four candidates from the original review looked plausible enough to plan for (fixing or filing),
but did not survive a second, closer read against the actual code, done while implementing
MARXY-290:

- **A claimed CRLF-boundary off-by-one in `packages/core/src/buffer/buffer.ts`'s `lineOf`.**
  Tracing the loop by hand shows the guard that looked like an off-by-one (`if (i < limit) line +=
  1`) is exactly what prevents one; the function is correct as written.
- **A claimed missing zero-size guard in `packages/core/src/render/images.ts`'s WebP VP8/VP8L
  decoding.** Both branches compute width/height as `(bits & 0x3fff) + 1`, so the result can never
  be zero; the finding (and the VP8X branch's own existing zero-check) both assumed a code shape
  that isn't actually there.
- **A claimed listener double-registration gap in `apps/desktop/src/palette/view.ts`'s
  `mountPaletteApp`.** No call site (production or test) invokes it more than once; a guard would
  be speculative hardening against a scenario that does not exist today, not a fix.
- **A claimed orphaned file-watcher on rapid theme restart in `apps/desktop/src/theme/user-theme.ts`.**
  The internal `generation` self-cancellation this would have extended cannot actually be reached
  from `restartUserTheme` or `adoptThemeDirectory`: nobody outside a `startUserTheme` call holds a
  reference to that call's own `stop()` until its promise has already resolved (including its own
  `shell.watch()` call), so the race the finding described is not constructible through any
  existing caller.

## Not filed, and why

- **`packages/core/src/sanitize/sanitize-html.ts`'s non-`img` remote-subresource gap:** no
  attribute in the current allow-list can trigger it; speculative until the allow-list grows.
- **`packages/core/src/sourcemap/section.ts`'s unasserted top-level-heading invariant:** holds
  today; nothing currently violates it.
- **`packages/core/src/parse/byte-offsets.ts`'s negative-offset asymmetry:** no real caller passes
  a negative offset; the strict-path implementation already clamps.
- **`packages/core/src/operations/align-table-pipes.ts`'s undocumented width-floor invariant:** the
  `Math.max(3, ...)` floor makes it safe today; a comment would be enough, not a story.
- **`packages/theme/src/loader.ts`'s "delete the whole declaration on an unparseable value"
  behaviour:** matches the documented intent (leave the default kept); the comment's wording is
  loose, the behaviour is not a bug.
- **`apps/desktop/src/palette/search.ts`'s frecency ranking short-circuit:** no concrete inversion
  found, low confidence.
- **`apps/desktop/src-tauri/src/commands/fs.rs`'s `mtime_ms` truncating cast:** harmless at any
  realistic filesystem date.
