> A filing pass, not a periodic one. The 2026-09-26 handoff (after MARXY-246, #219) found that
> both health reviews hit the same pattern: **each module is right on its own, and the seams
> between them are wrong and untested.** This pass ran every suspicion it could against
> `origin/main` at `ee33feb`, filed what reproduced, and dropped what did not. Landing key

## What this pass does

1. **Seven stories**: five in Phase 3 (epic MARXY-40) and two in the ops lane. None goes into a
   closed phase, and the earlier phases in `deps.json` are unchanged.
2. **One ADR.** [ADR-0037](../../adr/0037-one-document-store.md) is **proposed**: one document
   store, where every change is a transition. The store story is `human-gated` until the author
   accepts it, and the MARXY-248 session claims it.
3. **Edits to three existing rows:**
   - MARXY-45 now owns the orphaned Rust index module and the path scope of every command.
   - MARXY-49 now depends on the store and deletes the write-on-operation.
   - MARXY-240 records the author's decision on relative links.
4. **Evidence**: every reproduction is kept in [`evidence/2026-09-27-seams/`](evidence/2026-09-27-seams/),
   so each story starts from a test already shown failing.

## Decisions recorded

- **Relative markdown links open in Marxy** (the author, 2026-09-27; MARXY-240). They replace the
  current document, `Mod+[` returns to the previous one, and a link that resolves outside the open
  document's root is refused with a notice.
- **`displayWidth` matches CodeMirror's monospace cell widths.** Source mode is the only place a
  Marxy reader sees aligned pipes (seams-corpus).
- **The path scope** for `read_file`, `write_file_atomic` and `allow_asset_scope` is the open
  document's root (ADR-0012, computed by the now-declared index module) plus the config and theme
  directories (MARXY-45).
