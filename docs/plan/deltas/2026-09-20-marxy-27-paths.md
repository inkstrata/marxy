## MARXY-27 — PR #124 self-widened `Paths` to add a dependency it genuinely needed

MARXY-27's row named `packages/core/src/highlight, scripts/allowlists`. Highlighting through Shiki
means `packages/core/package.json` gains `@shikijs/*` as a runtime dependency, and that file sat
outside the row. PR #124 (attempt 1) added the dependency *and* widened its own `Paths` cell in the
same diff to cover it — the same self-grant `docs/plan/deltas/2026-09-19-marxy-83-paths.md` and the
MARXY-131 landing story both exist to refuse: a story that can edit its own boundary has no boundary,
and two implementors doing it in parallel leave the occupancy rule meaning nothing. The reviewer
returned it correctly. The diagnosis in the PR was right; making the correction is the planner's job.

**Decision.** `Paths` for MARXY-27 becomes `packages/core/src/highlight, scripts/allowlists,
packages/core/package.json`. Nothing else on the row changes — not Summary, not Acceptance, not the
dependency edge. `docs/plan/jira-issues.csv` is not added to MARXY-27's own `Paths`, and never should
be, for the reason above. #124 stays open; its attempt 2 keeps the highlighter code and the
`packages/core/package.json` dependency hunk, and drops the CSV hunk it authored on itself, since this
delta lands that cell instead.

One thing for whoever reviews attempt 2 and is not this delta's job to pre-empt: ADR-0006 refuses a
GPL grammar. `scripts/allowlists` was already in MARXY-27's `Paths` for exactly this — every grammar or
theme package Shiki pulls in needs a licence recorded there before `pnpm gate:licences` can pass, the
same rule every other allow-listed dependency already clears. This delta does not audit Shiki's
grammar set; it only grants the `package.json` edit the dependency itself needs.

**Decision.** `Paths` for MARXY-126 becomes `scripts/check-cards.mjs, scripts/check-cards.test.mjs,
