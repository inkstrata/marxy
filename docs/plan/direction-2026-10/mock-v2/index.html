HOW TO USE THESE

Every control is live: transforms and copy formats really run and write to the clipboard, the source editor really edits, settings persist across pages in this browser. Things that need the operating system (Finder, Services) are simulated and say so. Press ⌘K (or Ctrl K) on any page for the palette, and ⌘\ (Ctrl \) to fold or unfold the workspace: the Workspace page starts folded, and moving the pointer to the left, right or top edge peeks the sidebar, inspector or toolbar. Served locally with python3 tools/serve.py 8797 from this folder (a no-cache static server); the pages also open straight from disk.
