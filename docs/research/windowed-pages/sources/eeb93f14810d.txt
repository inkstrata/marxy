Reported
2024-11-29 23:19:05 PST

Created attachment 473400 [details]
Reduced test with some off-screen content skipped with `content-visibility: auto`.

Content skipped with `content-visibility: auto` should still be findable with find-in-page features and in Safari it’s not. I did confirm that content is still accessible in VoiceOver (e.g. if the skipped content includes a link, it’ll surface in the Web Rotor).

Latest draft spec (this is not a recent change): https://drafts.csswg.org/css-contain/#valdef-content-visibility-auto

Safari version 18.1.1 (20619.2.8.11.12)
