### Proposal

Markdown rendered in places, such as Wikis, get truncated [because of this code section](https://gitlab.com/gitlab-org/gitlab/-/commit/de3ea3cb762bb8d08d4419e048a171b4719aaf5e). Instance admins should be able to turn off this limit or change the maximum rendered limit. Doubling this from 1MB to 2MB would greatly improve usage for customers that rely on Wiki features for internal documentation.
