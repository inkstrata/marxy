Modern CSV is a powerful CSV file editor/viewer application for Windows, Mac, and Linux. Professionals at all levels of technical proficiency use it to clean CSV files, analyze data, check files for uploading to databases, modify configuration files, maintain customer lists, and more. We designed it to compensate for the deficiencies of spreadsheet programs in handling CSV/TSV/DSV/etc. files. We strive to create a user experience our customers describe as “blissful”.

Edit CSV Files Quickly and Easily

Why should moving columns, duplicating rows, or splitting cells be difficult?

Modern CSV makes everyday editing tasks effortless. Select entire rows or columns or multiple cells and perform operations on all of them at once.

With intuitive controls and an extensive collection of commands, even complex editing tasks become simple.

Find, Sort, and Filter Your CSV Data

Find exactly what you're looking for, even in large datasets.

Search with regular expressions, highlight matches as you type, and preview replacements before making changes.

Sort columns with a double-click, create powerful filters, and hide rows or columns to focus on the data that matters.

Open Large CSV Files With Ease

Modern CSV is designed to handle files that overwhelm most spreadsheet applications. Its optimized file handling engine enables fast loading, responsive editing, and low memory usage.

Testing shows Modern CSV can load a file 28 times faster than Excel. Furthermore, it handles files beyond Excel’s million-row limit.

An Easy and Customizable CSV Editor Interface

Modern CSV was designed with you in mind. Its clean, intuitive interface makes it a breeze to use its powerful tools on your CSV files.

Features like Auto-Suggest simplify data entry, Column Tools helps you quickly filter, sort, and analyze column data, and the Command Launcher lets you find and execute commands quickly.

Make Modern CSV your own by setting your own keyboard shortcuts, picking from a wide variety of light and dark themes, and telling it how to open files according to file extension.

Analyze Your CSV Files

Modern CSV’s built-in analysis tools help you uncover insights about your CSV files.

Statistics - Quickly calculate the mean, median, variance, and other statistics.

Column Analysis - Examine data types, empty cells, and column characteristics.

Unique Values - Identify unique entries across one or multiple columns and see their frequencies.

Pivot Tables - Group and summarize your data to reveal patterns.

Charts - Visualize your data with line, scatter, histogram, bar, and pie charts.

Extend Modern CSV with Plugins

Need more advanced capabilities? Modern CSV's plugin system lets you extend the application with tools for automation, scripting, and data processing.

Install only the plugins you need to keep the program lightweight.

The following plugins are currently available and more are in development.

Formulas - Perform calculations on your data with Python.

Scripts - Write your own commands with Python and record macros.

Terminal Commands - Integrate external programs into your workflow and pass file data or metadata through command-line arguments.
