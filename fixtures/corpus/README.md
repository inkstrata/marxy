# Fixture corpus

The documents every golden, fidelity, no-network and aesthetics walk uses.
Numbered files are the cases. This file records provenance for anything whose
licence is not obvious from being original to an MIT tree.

## 15-prose-volume.md

Original continuous prose written for MARXY-64 so the line-breaking study has a
sample that can carry a comparison, rather than the ten paragraphs that decided
MARXY-19. It is not imported from the brainstorm tree, and it does not vendor
CommonMark or GFM specification examples (those are CC-BY-SA-4.0; ADR-0006).

Licence: MIT, same as the rest of this repository. No third-party text is
vendored in it. `pnpm gate:licences` stays green because nothing copyleft
entered the lockfile or the corpus.

The machine check for volume and shape is `check-prose-volume.mjs` in this
directory. `image.png` is a 1200×400 PNG for local image tests in
`09-gfm-everything.md` (MARXY-138).

## 28-llm-answer.md

Original text written for MARXY-346: the kind of answer a person pastes from a chat assistant
into a file, with the habits that survive the paste (an emoji title, hand-typed bullet characters,
numbering that restarts after a code block, a sentence that a following `---` turns into a
heading, a fence that contains a whole other document). Every name, address and value is invented;
hosts use `example.invalid` (RFC 2606). One line ends in two spaces on purpose. It does not
vendor CommonMark or GFM specification examples (CC-BY-SA-4.0; ADR-0006).

## 24-issue-thread.md

Original text written for MARXY-346: an issue and a pull-request review thread exported to
markdown, with raw HTML, a collapsed log, ESC bytes (0x1B, thirty-eight of them, on purpose) and
two remote images. Handles, names and addresses are invented; the `Co-authored-by:` trailers name
invented people and are fixture content, not attribution for this repository. Do not let an
editor or formatter strip the ESC bytes: `.gitattributes` marks `fixtures/corpus/**` as `-text`
so that they, and every other byte in this directory, are stored as written.

## 30-notebook-export.md

Original text written for MARXY-346, modelled on the structure of a Jupyter notebook exported
with `nbconvert --to markdown`: fenced code, indented outputs, pandas-style HTML tables, a
traceback, a long single-line output, one image referenced by a file that is absent on purpose
(`output_7_0.png`) and one inline `data:image/png;base64,` image that is a valid 69-byte 1x1 PNG
generated for this file. The data are synthetic. No notebook, output or CSS from any third party
is vendored.

## 31-essay.md

Original long-form prose written for MARXY-346 as a second sample for typesetting comparisons
beside `15-prose-volume.md`. The harbour, the keeper and the verses are invented; the facts
about tides are general knowledge stated in the author's own words. It names no real person and
quotes no published text; the epigraph and the French paragraph are original. Five lines of
verse end in two spaces and five end in a backslash on purpose, to test both hard-break forms.

## 32-long-reference.md

Generated by `gen-long-reference.mjs` in this directory for MARXY-346: a reference manual for an
invented product ("Brindle"), built to be large (about 195 KB, 395 headings, 120 fences, 60
tables, 123 anchor links, a 200-line changelog, 30 footnotes). Run `node gen-long-reference.mjs`
to regenerate it byte for byte; the generator has a fixed seed, uses no clock or random source
and has no dependencies. `--large` writes a 241 KB variant, which is not part of the corpus
because its page is taller than the aesthetics grid check can hold (list items about 164,000 px
down drift 0.52 px off the grid, past the 0.5 px tolerance). The introduction is hand-written prose in the generator; everything else is
assembled from short templates. Nothing is third-party text.

Licence: MIT, same as the rest of this repository, for all five files and the generator.
`pnpm gate:licences` is unaffected because nothing copyleft entered the lockfile or the corpus.

## 35-build.log

Original text written for K-08: a service log in the usual shape (an ISO timestamp, a level word, a
component, a message), with every case a log reader meets: DEBUG, INFO, WARN, ERROR and FATAL
heads; stack frames and a blank line that continue an error; a hint that continues a warning; a
level word inside a message that is not a level; a tab inside a line; and two ANSI escape sequences
(ESC, 0x1B, four of them on purpose). Every name, host and number is invented; the host is
`harbor.example.invalid` (RFC 2606). Do not let an editor or formatter strip the ESC bytes:
`.gitattributes` marks `fixtures/corpus/**` as `-text`.

## 36-change.diff

Original text written for K-09: a unified diff in the shape `git diff` writes, two files and three hunks. It has
added, removed and context lines, an `index` line, hunk headers with a function name after the second `@@`, one added line
long enough to wrap in the reader (the hang past the marker column), and a `\ No newline at end of file` note. Every name
is invented. A `.diff` opens in Read; the goldens move only if the code-file parse or the kind table does.

## 38-shell.session

Original text written for K-17: a shell session in `user@host dir %` prompts, three commands. The second is continued with a
backslash (one command on two lines); its output holds blank lines that stay in it; the third prints one ANSI escape pair
(ESC, 0x1B, on purpose) and a `$` inside a line of output, which is output and not a prompt. Every name and path is invented.
A `.session` opens in Read. The number is shared with `38-awkward.csv`, which is a table and not a session.

## 39-changelog.md

Original text written for K-22: a changelog in Keep a Changelog order with an `Unreleased` section first (which Copy release notes
skips), three dated versions (one heading a link, one with its date in the same line), a fenced block that holds a line that
looks like a release heading and is not one, and reference links at the end. Every name is invented; the links are `example.invalid`.
Its name does not begin `CHANGELOG`, so the corpus reads it as an article; the tests open its bytes under a changelog's name.

## 33-article-byline.md

Original text written for K-20: a short essay whose YAML front matter names an author (quoted, to exercise the one pair
of outer quotes the byline drops), a date and a web source with a path and a query, after a title, a description and a
list of tags, so the byline's rows move ahead of rows the bytes put first. Its opening paragraph is wholly in emphasis
directly after the title; the description is the dek, so that paragraph stays a paragraph (the key wins). Every name is
invented; the source is `example.org` (RFC 2606).

## sections.md and sections-crlf.md

Original text written for W-10: the document the Outline tab's moves are tried on, twice, the second with every line ending CRLF.
It has front matter holding a `#` line, an introduction before the first heading, two ATX sibling sections with a section of their
own below one of them, a fence, a quote and a list item that each hold a `#` line that is not a heading, a table, two setext
headings (`===` and `---`), a heading indented by three spaces, and a last section with no final line ending and no full stop (so the file ends on a
text byte, in both, and a move of that section changes the file's last byte on purpose). The goldens move only if the parse does.

The two files have no number on purpose: the numbered `.md` files are the reading corpus, and each owes the aesthetics gate a screenshot baseline for
each engine (`packages/theme` tests, `gate-aesthetics.mjs`, `probe-layout.mjs`). These are text for operations and the save path to be tried on, not pages to be
judged, so the goldens, the fidelity gate and the operation tests read them and the aesthetics gate does not.
## 37-results.csv

Original data written for K-10b: a benchmark table in the shape of the mock's `bench-csv` (a corpus name, five numbers and
a host), eight rows under a header row of distinct words, so the table lens uses row 1 as its header. `cold_ms` holds
numbers whose text order is not their numeric order (`9900` after `118400` as text), which the sort test reads. Every name
and number is invented.

## 38-awkward.csv

Original data written for K-10b: every case the table lens must show honestly, in one CRLF file that starts with a UTF-8
byte-order mark. A quoted field holding a comma; a doubled quote (`"said ""hello"""`, a decoded cell); a quoted CRLF inside
a field; empty fields; a short row and a long one (ragged); a byte after a closing quote (`"Gil"x`, an unreadable row); a
blank line; a bidi control (U+202E) and a zero-width space inside a quoted field; a space before a quote (` "spaced"`,
verbatim); an unclosed quote on a line of its own, with a well-formed row after it; and cells a spreadsheet would run
(`=SUM(…)`, `+cmd`, `@risk`) next to a plain `-5`. Every name and number is invented.
