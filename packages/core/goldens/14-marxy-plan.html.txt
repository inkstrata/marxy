<h1 data-marxy-s="0" data-marxy-e="21">Implementation plan</h1>
<p data-marxy-s="23" data-marxy-e="396">Five phases. Each ends in something runnable and reviewable, and each ends with a scheduled
taste review. Risky and load-bearing work comes first: the typography path and the Linux
question before the index, and the index before operations, which are easy and endlessly
extensible. Stories with acceptance criteria are in <code data-marxy-s="345" data-marxy-e="367">plan/jira-issues.csv</code>; this document is
the shape.</p>
<p data-marxy-s="398" data-marxy-e="492">Estimates assume an agent fleet with one human reviewing; they are for ordering, not promises.</p>
<h2 data-marxy-s="494" data-marxy-e="548">Phase 0 — Foundations and a release (≈ 2 weeks)</h2>
<p data-marxy-s="550" data-marxy-e="780"><strong data-marxy-s="550" data-marxy-e="564">Ends with:</strong> v0.0.1 installs on macOS and Linux, opens a markdown file passed on the command
line, renders it unstyled, and every CI gate exists (some as skeletons that pass trivially).
Taste review #0 chooses the typeface pair.</p>
<ul data-marxy-s="782" data-marxy-e="2062">
<li data-marxy-s="782" data-marxy-e="939">Contracts frozen: AST + source map, operation, shell-api, theme tokens, index entry,
reading position (<code data-marxy-s="889" data-marxy-e="915">packages/*/src/contracts</code>). ADR needed to change.</li>
<li data-marxy-s="940" data-marxy-e="1022">Corpus committed (<code data-marxy-s="960" data-marxy-e="977">fixtures/corpus</code>) and golden files generated from the parser.</li>
<li data-marxy-s="1023" data-marxy-e="1190"><code data-marxy-s="1025" data-marxy-e="1040">packages/core</code>: parser (markdown-it, CommonMark + GFM) producing the AST with byte
provenance; sanitiser; outline. Passes the CommonMark spec suite. Runs in Node.</li>
<li data-marxy-s="1191" data-marxy-e="1372"><code data-marxy-s="1193" data-marxy-e="1207">apps/desktop</code>: Tauri shell implementing <code data-marxy-s="1234" data-marxy-e="1245">shell-api</code> (read, atomic write, watch, dialogs,
clipboard, single-instance). Loads the frontend; renders the AST to HTML with no theme.</li>
<li data-marxy-s="1373" data-marxy-e="1713">CI: build/typecheck/lint/test; golden files; licence audit (real); no-network gate (real,
over the corpus in Playwright); byte-fidelity property (real, over open→save); perf gate
reading budgets (cold start measured on the packaged app on both runners); bundle gate;
screenshot diff and aesthetics gate wired with empty baselines.</li>
<li data-marxy-s="1714" data-marxy-e="1884">Release workflow: tag → macOS DMG (signing and notarization steps gated on secrets) and
Linux AppImage; publish as pre-release. Branch protection and CODEOWNERS on.</li>
<li data-marxy-s="1885" data-marxy-e="2062">Taste review #0 artifact: the long corpus document set in Literata + JetBrains Mono and in
Source Serif 4 + IBM Plex Mono, at the type scale, exported as PNG at 1× and 2×.</li>
</ul>

<li data-marxy-s="2390" data-marxy-e="2561">Bundled fonts with <code data-marxy-s="2411" data-marxy-e="2423">@font-face</code>, <code data-marxy-s="2425" data-marxy-e="2439">font-display</code>, preload; fonts on the critical path,

<li data-marxy-s="2998" data-marxy-e="3240">Images with reserved dimensions from the file’s intrinsic size (via shell-api), remote

<li data-marxy-s="3241" data-marxy-e="3326">Smart typography render pass. Tier 1 aesthetics gate turned on with real baselines.</li>
<li data-marxy-s="3327" data-marxy-e="3398">Screenshot baselines committed for WebKit (Playwright) and WebKitGTK.</li>

<h2 data-marxy-s="5562" data-marxy-e="5582">How the loop runs</h2>
<p data-marxy-s="5584" data-marxy-e="5950">plan → stories with executable acceptance criteria and listed paths → implement in parallel
where paths do not overlap → machine gates → PR with why, ADRs, artifacts → merge → queue
entry → phase-end taste review → ADRs and <code data-marxy-s="5824" data-marxy-e="5835">AGENTS.md</code> updated. Context loss is handled by the
repo being the memory; drift by screenshot diffs and constraints-as-gates.</p>
