<h1 id="rooftop-sensor-readings-a-first-look" data-marxy-s="0" data-marxy-e="39">Rooftop sensor readings: a first look</h1>
<p data-marxy-s="41" data-marxy-e="225"><em data-marxy-s="41" data-marxy-e="225">Exploration notebook, exported with <code data-marxy-s="78" data-marxy-e="111">jupyter nbconvert --to markdown</code>. Kernel: Python 3.12. The data are synthetic and were generated for this example; no real stations are involved.</em></p>
<p data-marxy-s="227" data-marxy-e="614">We want to know whether the sensor on the north roof drifts relative to the one on the south roof. The model is simple: if both sensors see the same air, the difference <code class="marxy-math" data-marxy-s="396" data-marxy-e="418">\Delta T = T_N - T_S</code> should have a mean close to zero, and any slow trend in it is drift. Write the drift rate as <code class="marxy-math" data-marxy-s="512" data-marxy-e="520">\alpha</code> degrees per week, so that over <code class="marxy-math" data-marxy-s="552" data-marxy-e="555">n</code> weeks we expect <code class="marxy-math" data-marxy-s="572" data-marxy-e="613">\Delta T \approx \alpha n + \varepsilon</code>.</p>

<b>Note:</b> every cell below was run top to bottom on a fresh kernel. Cell numbers in the margin of the original notebook were removed by the export.

<h2 data-marxy-s="8855" data-marxy-e="8871">7. Conclusion</h2>
<p data-marxy-s="8873" data-marxy-e="8977">The south sensor and the north sensor agree to within a few hundredths of a degree per week. We can say:</p>
<ul data-marxy-s="8979" data-marxy-e="9206">

<li data-marxy-s="9047" data-marxy-e="9149">the noise in <code class="marxy-math" data-marxy-s="9062" data-marxy-e="9072">\Delta T</code> has a standard deviation near <code class="marxy-math" data-marxy-s="9103" data-marxy-e="9109">0.33</code>, so a single reading cannot show drift;</li>
<li data-marxy-s="9150" data-marxy-e="9206">a table of the weekly values is in the appendix below.</li>
</ul>
