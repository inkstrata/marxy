<p data-marxy-s="829" data-marxy-e="1006">The machine check for volume and shape is <code data-marxy-s="871" data-marxy-e="895">check-prose-volume.mjs</code> in this

<h2 data-marxy-s="2668" data-marxy-e="2682">31-essay.md</h2>
<p data-marxy-s="2684" data-marxy-e="3152">Original long-form prose written for MARXY-346 as a second sample for typesetting comparisons

<h2 data-marxy-s="3154" data-marxy-e="3177">32-long-reference.md</h2>
<p data-marxy-s="3179" data-marxy-e="3945">Generated by <code data-marxy-s="3192" data-marxy-e="3216">gen-long-reference.mjs</code> in this directory for MARXY-346: a reference manual for an
invented product (“Brindle”), built to be large (about 195 KB, 395 headings, 120 fences, 60
tables, 123 anchor links, a 200-line changelog, 30 footnotes). Run <code data-marxy-s="3435" data-marxy-e="3464">node gen-long-reference.mjs</code>
to regenerate it byte for byte; the generator has a fixed seed, uses no clock or random source
and has no dependencies. <code data-marxy-s="3585" data-marxy-e="3594">--large</code> writes a 241 KB variant, which is not part of the corpus
because its page is taller than the aesthetics grid check can hold (list items about 164,000 px
down drift 0.52 px off the grid, past the 0.5 px tolerance). The introduction is hand-written prose in the generator; everything else is
assembled from short templates. Nothing is third-party text.</p>
