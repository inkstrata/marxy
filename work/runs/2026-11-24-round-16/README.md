## Briefs

### budgets-4 (lines of text)
1. `paste/classify.ts:29-30` `TABLE_DELIMITER` and `INLINE_MARKS` are O(n^2) on a line of spaces or `[`, and a paste has no length cap. Make the patterns linear (or test a bounded prefix of each line) and cap how much of a paste is classified. Proof: a hostile paste (one long line of spaces, one of `[`) classifies in bounded time; the existing classify cases unchanged.
2. `reading/index.ts:1094-1112` `carriesMarkdown` is O(L^2) per line for lines up to 1000 chars, and lines are not counted below 5 MB, so verse and prose readings draw every line. Make the per-line check linear and bound the lines looked at. Proof: a hostile file (many 1000-char lines that defeat the check) in bounded time; readings of ordinary files identical (differential against base).
3. `reading/rows.ts` JSON Lines: each line is parsed whole with no per-line byte cap. Cap the bytes parsed per record; a record past it is shown as a cut row the reader can see, not dropped silently. Proof: a 50 MB single-line record in bounded time and memory, the row says it was cut.
4. `diff/words.ts` tokenises every line of a run before the `MAX_TOKENS` check. Stop tokenising once the cap is reached. Proof: a run of very long changed lines in bounded time; word diffs of ordinary runs identical.
Docs: extend "Work on untrusted files" in `docs/architecture.md`, in its own paragraph.

### budgets-5 (containers)
1. `viewer/archive.ts:143-145` `archiveSums` joins every prefix of every path: up to ~1e9 character copies within the caps. Build the folder sums from the path segments without re-joining (a trie or a parent index). Proof: a hostile archive listing (100,000 entries, 64 segments, long names) sums in bounded time; sums of ordinary archives identical.
2. `office/xml.ts:367-379` `find` is a BFS with `todo.shift()`, quadratic on wide trees up to 2M elements. Use an index head instead of `shift`. Proof: a wide hostile document in bounded time.
3. `book/package.ts:225-237`: headings without links do not add depth, so `TOC_DEPTH` 8 is bypassed. Count depth by nesting, whatever the heading holds. Proof: a TOC nested past 8 through link-less headings is cut at 8.
4. `mail/mime.ts` `delimiters`: each nesting level rescans its range, O(depth x bytes). Find each level's delimiters within the parent's part ranges only, or bound the bytes scanned. Proof: a 12-deep hostile message near 64 MB in bounded time; parts of ordinary messages identical. Also add the missing tests for `headers` (1000) and `headerBytes` (256 KiB).
5. `viewer/cert.ts:118-121` `checkTree` has no node count cap. Cap nodes with the shared budget; the cert card says when it stopped. Proof: a hostile DER with many small nodes stops at the cap and says so.
Docs: as budgets-4, in its own paragraph.

### teardown-2 (F24)
Round 15's `shell-teardown` held opens drained by the first take until a boot subscribes, and gave the menu watch and close guard disposers. What it left:
1. An open emitted live by Rust (after the first take) while no boot is subscribed is dropped. Hold it the same way as the drained ones, delivered once to the next boot.
2. `createDocumentSignal` keeps its pane subscriptions after destroy until the panes go. Drop them on destroy.
3. If a boot's open callback throws, the held batches after it are lost. Deliver each batch independently, so a throw loses at most its own batch, and log the throw.
Proof: browser or unit tests that boot, destroy, boot again and show each leftover gone; each fails on base.
